# Внешние датасеты для усиления CatBoost

**Решение команды (24.10.2026): используем только российские данные.** Объединение и обучение — в ноутбуке `analytics/catboost_merged.ipynb`. Зарубежные наборы (Berka, M5, Rossmann, Favorita, индийские МСП и др.) не берём: чужой календарь, праздники, налоги и поведение бизнеса дают сдвиг распределения, который потом придётся вычищать.

Задача CatBoost у нас — прогноз дневного «шумного» потока компании (розница + нерегулярные платежи, слои B+C). Известные события — регулярные платежи, налоги, счета — добавляются поверх. Поэтому внешние данные ценны в двух ролях: **(а)** напрямую — дневной поток денег по компаниям; **(б)** косвенно — отраслевые и сезонные профили для компаний с короткой историей.

Лицензии и состав полей перед скачиванием проверить на странице источника.

## Как смешивать, чтобы не было дисбаланса

Главный риск: внешних строк будет в тысячи раз больше, чем наших, и модель выучит «чужие» компании. Механика уже есть в `app/domain/ml_flow.py` и покрыта тестами.

1. **Цель без масштаба.** Поток в долях обычного дневного оборота компании (`scale_of()`), а не в рублях — крупные клиенты MBD не перетягивают модель.
2. **Признак источника** `source` (`case` / `mbd` / `1c_retail`). При прогнозе для нас всегда подаётся `source=case`.
3. **Отбор похожих окон** (`adversarial_filter()`): классификатор «наше или внешнее» с разбиением по компаниям; внешние окна с P(внешнее) > 0,8 выкидываем. На синтетике похожих остаётся 98,7%, отличающихся — 0,7%.
4. **Веса** (`mix_weights(case_share=0.5)`): суммарный вес наших строк — не меньше половины выборки.
5. **Проверяем только на наших.** Тем же бэктестом на отложенных компаниях кейса. Внешние данные оставляем, только если улучшают MASE на h=20–30 и не ухудшают метрики разрывов.

Если смешивание не даст прироста — предобучить CatBoost на MBD и дообучить на кейсе (`init_model`) или подать прогноз «внешней» модели как признак.

## Что ещё даст прирост без внешних данных

- **Больше окон из своего датасета:** шаг отсечки 1 день вместо 5 — в 5 раз больше строк без сдвига распределения.
- **Аугментация своими компаниями:** сдвиг окна по времени, умножение оборота на коэффициент (цель нормирована, это честно).
- **Признаки из домена:** доля дебиторки по счетам, сумма известных событий на горизонте, сезонный индекс отрасли из СберИндекса.
