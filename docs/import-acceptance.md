  Модели не обучались, качество прогноза этим прогоном не оценивалось.

`quality.rows_rejected` сообщает число отброшенных записей CSV. Предупреждение содержит первые
20 номеров записей (с учётом заголовка) и названия неверных полей, без исходных значений.
В многофирменном файле это общий отчёт по файлу, повторённый в результатах компаний.
Если корректных записей нет, API отвечает 422 без частичной записи данных.

Чтобы повторить архивную приёмку, в PowerShell из `backend/` задайте
`$env:CASHFLOW_ACCEPTANCE_ARCHIVE='C:/data/cashflow_dataset_participants.zip'`
и отдельную тестовую базу через `CASHFLOW_DATABASE_URL`, затем выполните
`uv run --no-sync pytest tests/test_case_archive.py`.
Без архива эти две проверки пропускаются. Датасет в git не добавляется.
